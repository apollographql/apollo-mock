# Apollo Mock

[![Build status](https://github.com/apollographql/apollo-mock/actions/workflows/build-pull-request.yaml/badge.svg)](https://github.com/apollographql/apollo-mock/actions/workflows/build-pull-request.yaml)

Apollo Mock is a framework to generate and serve mock data for your testing or experimentation needs. It uses Large Language Models to generate realistic user data.

📖 See the [documentation](https://apollographql.github.io/apollo-mock/) to get started.
